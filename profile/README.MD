## About

**Custom ROM resources and device trees for the POCO X7 Pro (`rodin`).**

### What we maintain

- Device Tree
- Kernel
- Proprietary Vendor
- MediaTek Hardware
- Xiaomi Hardware
- SELinux Policies
- Recovery & ROM development
